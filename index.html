隐私政策

适用扩展：跨境电商工具箱（Cross-border Trade Toolkit）· 开发者：edong · 生效日期：2026-10-14

一句话概括：本扩展没有账号体系，没有统计、广告或追踪脚本；开发者不运行任何服务器，也不会收到你的任何数据。你的设置只保存在你自己的浏览器里，图片只在你的电脑上处理。

1. 保存在你设备上的数据

为了让你下次打开时保持习惯设置，扩展会把以下内容保存在浏览器本地存储（chrome.storage.local）中，不会同步给开发者：

  • 界面语言、上次使用的工具；
  • 时区工具中的主时区和城市列表；
  • 汇率工具中的常用币种、点差设置、以及缓存的汇率表（6 小时）；
  • 各工具上次选择的国家 / 选项（例如邮编工具的国家、美国关税的原产国）；
  • 图片工具的选项和你添加的自定义尺寸预设。

你可以随时在浏览器的扩展管理页面卸载扩展或清除扩展数据，这些内容会一并删除。

2. 联网请求（仅在你主动查询时发生）

部分功能需要实时数据。此时你的浏览器会直接向下列公开服务发出请求（不经过开发者的服务器）：

功能服务发送的内容
美国关税、HS 编码在线检索美国国际贸易委员会 hts.usitc.gov你输入的 HS / HTS 编码或英文关键词
邮编查地址api.zippopotam.us；备用 nominatim.openstreetmap.org（OpenStreetMap）你输入的邮编和所选国家
汇率换算open.er-api.com；备用 cdn.jsdelivr.net、api.frankfurter.dev无用户数据，只是获取当日汇率表

这些第三方服务会像任何网站一样看到连接信息（例如 IP 地址、浏览器类型），并按各自的隐私政策处理，我们无法控制。扩展不会向它们发送 Cookie、账号信息、你正在浏览的网页或任何你没有主动输入的内容。

此外，部分结果旁边有跳转链接（如欧盟 TARIC、Access2Markets、OpenStreetMap 地图、美国 HTS 官网）。只有你点击后才会在新标签页打开对应网站。

3. 图片处理

图片压缩和平台尺寸预设完全在你的浏览器内（本机内存）处理，图片不会被上传到任何服务器。输出的图片会去掉 EXIF 等元数据（包括拍摄位置）。

4. 权限说明

  • storage：保存上述本地设置；
  • clipboardWrite：点击结果时复制到剪贴板；
  • 站点权限（hts.usitc.gov、api.zippopotam.us、nominatim.openstreetmap.org、open.er-api.com、cdn.jsdelivr.net、api.frankfurter.dev）：仅用于第 2 节所述的查询。

扩展不读取你浏览的网页内容，不使用内容脚本，不加载远程代码。

5. 我们不会做的事

  • 不出售、不出租、不向第三方转让用户数据（第 2 节中由你主动触发的查询除外）；
  • 不把用户数据用于与扩展功能无关的目的；
  • 不把用户数据用于判定信用度或贷款；
  • 不做用户画像、广告或行为追踪。

本扩展遵守 Chrome 网上应用店《用户数据政策》。

6. 儿童

本扩展面向从事跨境电商 / 外贸的成年用户，不针对儿童，也不会有意收集儿童的信息。

7. 政策变更

如果功能或数据处理方式发生变化，我们会更新本页并修改上方的生效日期。重大变化会同时体现在扩展的更新说明中。

8. 联系我们

关于本政策或扩展的任何问题，请联系：adoooing@gmail.com

Privacy Policy

Applies to: Cross-border Trade Toolkit (Chrome extension) · Developer: edong · Effective: 2026-10-14

In short: the extension has no accounts and no analytics, advertising or tracking scripts. The developer does not run any server and does not receive any of your data. Your settings stay in your own browser, and images are processed on your own computer.

1. Data stored on your device

So that the extension remembers your preferences, it stores the following in the browser's local extension storage (chrome.storage.local). It is not synced to the developer:

  • interface language and the last tool you used;
  • your home time zone and city list (Time Zones tool);
  • favourite currencies, spread / fee setting and a cached exchange-rate table (6 hours) (Exchange Rates tool);
  • the last selected country / option in some tools (for example the country in the Postal Lookup, the origin in the US Tariff tool);
  • image-tool options and the custom size presets you create.

Uninstalling the extension or clearing its data from your browser's extension settings removes all of this.

2. Network requests (only when you ask for a lookup)

Some features need live data. In that case your browser contacts the following public services directly (not through any server of the developer):

FeatureServiceWhat is sent
US Tariff and online HS searchUS International Trade Commission – hts.usitc.govThe HS / HTS code or English keyword you typed
Postal-code lookupapi.zippopotam.us; fallback nominatim.openstreetmap.org (OpenStreetMap)The postal code and country you selected
Exchange ratesopen.er-api.com; fallbacks cdn.jsdelivr.net and api.frankfurter.devNo user data – just a request for today's rate table

Like any website, these third-party services can see standard connection information (such as your IP address and browser type) and handle it under their own privacy policies, which we do not control. The extension does not send them cookies, account details, the pages you are browsing, or anything you did not type in yourself.

Some results include links (for example EU TARIC, Access2Markets, an OpenStreetMap map, or the US HTS website). They open in a new tab only when you click them.

3. Image processing

Image compression and marketplace presets run entirely inside your browser (in local memory). Images are never uploaded to any server. Output files have EXIF and other metadata (including GPS location) removed.

4. Permissions

  • storage – saves the local settings described above;
  • clipboardWrite – copies a result to the clipboard when you click it;
  • Host permissions (hts.usitc.gov, api.zippopotam.us, nominatim.openstreetmap.org, open.er-api.com, cdn.jsdelivr.net, api.frankfurter.dev) – used only for the lookups described in section 2.

The extension does not read the content of the pages you browse, uses no content scripts, and does not load remote code.

5. What we do not do

  • We do not sell, rent or transfer user data to third parties (apart from the lookups you trigger yourself, described in section 2);
  • We do not use user data for purposes unrelated to the extension's features;
  • We do not use user data to determine creditworthiness or for lending;
  • We do not profile users, show ads, or track behaviour.

The extension complies with the Chrome Web Store User Data Policy.

6. Children

The extension is intended for adults working in cross-border e-commerce and trade. It is not directed at children and does not knowingly collect information from them.

7. Changes to this policy

If the features or data handling change, we will update this page and the effective date above. Significant changes will also be mentioned in the extension's release notes.
